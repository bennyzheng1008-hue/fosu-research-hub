# 佛大选题资料库 · FOSU Research Hub

面向佛山大学多专业的毕设、竞赛与研究资料工作台。支持关键词搜索、专业筛选、四档项目难度、学习路线跳转和原始来源查阅。纯 HTML / CSS / JavaScript，站内检索在浏览器本地完成，无前端框架和第三方运行依赖。

## 难度分层

| 档位 | 定位 | 选题数 |
| --- | --- | ---: |
| D1 | 入门实践 | 17 |
| D2 | 课程综合 | 44 |
| D3 | 毕设进阶 | 33 |
| D4 | 科研挑战 | 8 |

按知识门槛、实现复杂度、资源依赖、验证要求分别给出 1–4 级，取最高维度作为当前范围的总体难度。每个选题包含先修知识、资源条件、主要瓶颈、最小版本、扩展路线、投入估计与协作建议。难度属于本项目的调研判断，不能替代学校或导师评估；准备阶段与项目难度独立。

页面只保留一个难度筛选，选中档位后显示选题。支持难度排序、重置，以及通过网址保留检索条件。大二集成电路可沿计数器 / PWM、FIFO 自动化验证、形式验证等相关方向逐步学习。

## 搜索与以赛带学

首屏采用一个搜索框、资料类型、专业和难度筛选；字段范围、关键词关系、领域和准备阶段放在可折叠的“精细检索”中。每条卡片只有标题一个详情入口。

- 默认同时匹配所有词；支持匹配任一词、完整短语与双引号短语。常见缩写自动展开，短英文缩写不会匹配单词中间的字符。
- 可限定标题、方案与报告、来源机构与网址。详细方案、先修条件、协作分工、文献检索式与完整集成电路报告均可搜索；命中片段高亮，标题与摘要优先参与相关度排序。
- 例：`RISC-V 验证`、`“跨个体” 牛`、`排程 CP-SAT`；查询来源时可选择“来源机构与网址”并搜索高校名称。
- 102 个选题都有候选竞赛、可用素材、协作分工、两周预研交付和待导师确认的问题；有合适证据时关联获奖案例。缺少接近案例会明确说明，不用其他方向的奖项代替。
- 案例保留真实届次和奖项，改编方案单独标为调研分析。公开毕设推荐公示仅作为题名线索；图书馆检索式不承诺全文权限。

详情中可进入关联竞赛、案例和工具，并返回上一条资料。所有关联都是准备建议，不表示本题已获奖或已经符合当前报名规则。

## 本机运行

需要 **Node.js 22 或以上**。没有需要安装的 npm 依赖。

```sh
git clone https://github.com/bennyzheng1008-hue/fosu-research-hub.git
cd fosu-research-hub
npm start
```

打开 <http://127.0.0.1:41847/>。服务只监听本机地址；在终端按 Ctrl+C 停止。也可以直接打开 `dist/index.html` 阅读，但建议使用本机服务。

Windows 安装 Node.js 后，可双击 `启动网站.cmd` 启动后台服务并打开浏览器；使用完双击 `关闭网站.cmd`。如默认端口被其他程序占用，启动会报错，不会关闭其他程序。

也可在终端使用自定义端口，例如 PowerShell：

```powershell
$env:FOSU_RESEARCH_PORT = '41848'
npm start
```

自定义端口适用于终端启动；双击脚本使用默认端口。服务不提供登录、写入接口或自动采集任务。点击外部来源和“到 Bing 继续搜索”会访问对应网站或 Bing；站内搜索的是整理后的资料快照。

## 更新资料与验证

编辑 `research-data.json`，再运行：

```sh
npm run build
npm run check
npm test
```

`generate.cjs` 校验 ID、专业关联、原始来源、选题难度档案、协作路线和关联链接，并生成 `dist/data.js`。修改数据后请同时提交 JSON 和生成文件。集成电路公开报告位于 `dist/downloads/ic-research.md`，应与 JSON 的 `report` 字段保持一致。

`expand-difficulty.cjs` 保存人工整理的拓展选题与评级规则；`refine-teacher.cjs` 保存后续案例与跨专业准备路线。需要重建这两批内容时，按先拓展、再完善、最后生成的顺序运行。脚本会按固定 ID 更新内容；人工维护后不要随意重跑覆盖自定义修改。

`ci/validate.example.yml` 提供 GitHub Actions 配置示例，可检查生成一致性、JavaScript 语法与本机服务。当前仓库未启用自动工作流；维护者可将示例放到 `.github/workflows/ci.yml`，并使用具备相应工作流写入权限的授权推送。

## 文件结构

```text
dist/                  可直接运行的静态网站
  downloads/           去除私人交流内容后的公开 Markdown 报告
research-data.json     资料主文件
generate.cjs           校验与生成 data.js
expand-difficulty.cjs  人工整理的难度拓展脚本
refine-teacher.cjs     获奖案例、毕设素材与跨专业准备路线
dist/search-engine.js  可在浏览器和 Node 中使用的检索模块
server.cjs             只读本机服务
tests/                 检索行为、关联完整性、公开内容与服务检查
start.ps1 / stop.ps1   Windows 启停脚本
```
